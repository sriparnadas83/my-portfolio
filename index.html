Projects

Project 1: Solar Tracker

This project involved the design and development of a solar tracking system aimed at maximizing energy efficiency by automatically adjusting the orientation of the sun rays on the fixed solar panels. Using a combination of mechanical design (AutoCAD, SolidWorks) and control systems, I was able to create a prototype that dynamically adjusts the angle at which the sun rays fall on the solar panels throughout the day. The system was further enhanced with web-based monitoring and data visualization to track performance and optimize energy output.

Project 2: Negotiation Sailors

Negotiation Sailors is an ongoing web-based platform aimed at allowing users to write, view, and manage their stories. The project integrates front-end web development using technologies like HTML, CSS, JavaScript, and React js, with the goal of creating an intuitive and engaging user interface. The platform is also designed to scale into a mobile app and provide a smooth user experience. The project emphasizes user-centered design, ensuring a seamless and enjoyable process for story publishing.
